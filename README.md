# PIONERO

## Viaje por la historia de San Patricio del Chañar

Experiencia interactiva de Ocarina Producciones.

### LEY MUNDIAL DE DESARROLLO

**COMPLEJO PARA CONSTRUIR → SIMPLE PARA USAR.**

PIONERO evoluciona como una arquitectura unificada. No se trabaja con parches aislados, remiendos ni regresiones. Cada avance debe quedar integrado, funcional, probado y preparado para la siguiente etapa.

### V0.1 — MOTOR DEL VIAJE

Flujo cerrado: abrir → presentación → elegir época → viajar → llegar → explorar → descubrir → volver.

Incluye motor de navegación, épocas, escenas, puntos de memoria, estados de evidencia, diseño responsive y separación entre datos históricos y lógica de experiencia.

### REGLA HISTÓRICA

Todo contenido debe distinguirse entre documentado, testimonio, reconstrucción e interpretación didáctica. Una reconstrucción nunca se presenta como una fotografía del pasado.

### ARQUITECTURA OBJETIVO

EXPERIENCE · TIME ENGINE · HISTORY ENGINE · TERRITORY ENGINE · MEDIA ENGINE · SOURCES ENGINE · EDUCATION ENGINE · CORE.

El contenido histórico deberá vivir separado del motor para poder ampliar el recorrido sin reescribir la experiencia.
