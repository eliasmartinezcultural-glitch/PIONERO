## V2.1 · Motor de relaciones

Esta rama convierte las huellas en un sistema de investigación.

El núcleo separa:

- **Eventos:** momentos del proceso histórico.
- **Capas:** territorio, agua, producción, comunidad e identidad.
- **Huellas:** puntos descubribles vinculados a cada momento.
- **Evidencia:** documentado, parcial, reconstrucción e interpretación.
- **Fuentes:** cada huella declara qué documentos la sostienen.
- **Relaciones:** varias huellas pueden formar una cadena causal o explicativa de investigación.
- **Pistas:** una relación permanece bloqueada hasta reunir las huellas necesarias.
- **Decisiones:** el jugador elige cómo interpretar la relación entre evidencias.
- **Consecuencias:** una respuesta correcta registra la conexión; una respuesta débil deja la pista abierta para seguir investigando.
- **Estado:** descubrimientos, respuestas, conexiones y recorrido quedan registrados durante la sesión.
- **Renderizado:** el paisaje visual responde al momento histórico.

### Regla fundamental

Las decisiones **no reescriben la historia documentada**.

Cambian el recorrido de investigación: qué conexión se registra, qué pista queda abierta y qué evidencia conviene volver a revisar.

Así PIONERO puede tener mecánicas de videojuego sin inventar hechos históricos.

### Primer mapa de relaciones

1. **Proyecto 1968 → Riego 1969 → Bocatoma 1971**
2. **Bocatoma 1971 → Parcelas → Fundación 1973**
3. **Fundación 1973 → Comisión de Fomento → Comunidad**

Estas tres relaciones son la primera prueba del motor. No son el techo del sistema.

## Dirección siguiente

El próximo salto no debe ser agregar cantidad de contenido.

Debe ser profundizar el sistema con:

- cadenas de pistas;
- documentos y fotografías como evidencia;
- testimonios diferenciados de fuentes institucionales;
- mapas y lugares;
- relaciones entre personas, obras, territorio e instituciones;
- consecuencias de investigación;
- actividades breves que obliguen a contrastar fuentes;
- memoria de lo que el jugador ya descubrió.

**PIONERO no debe ser una línea de tiempo decorada.**

Debe convertirse progresivamente en un **sistema de descubrimiento histórico del territorio**.
