# PIONERO — Atlas de referencias visuales

## Regla

Una imagen puede ser:

- evidencia histórica;
- referencia territorial;
- referencia morfológica;
- reconstrucción;
- interpretación.

**Nunca se presenta una referencia de otro lugar como fotografía de San Patricio del Chañar.**

## Paisaje base del pasado

Las fuentes locales y territoriales consultadas describen el área como una **meseta desértica / estepa patagónica**, con bardas, vegetación baja y un corredor del río Neuquén. El CFI describe específicamente el valle inferior del río Neuquén como una hendidura longitudinal en la meseta desértica, con estepa patagónica y arbustos bajos. La Municipalidad describe las tierras de 1968 como "monte bruto". 

Por eso la reconstrucción visual de 1968-1973 debe partir de:

**MESeta + suelo árido + horizonte amplio + arbusto bajo + río + vegetación concentrada donde aparece el riego.**

No debe partir de dunas.

## Uso

Las referencias sirven para construir una **reconstrucción visual plausible**, no para afirmar que una fotografía tomada en Santa Cruz representa Chañar en 1968.

La etiqueta visible recomendada para estas escenas es:

**RECONSTRUCCIÓN VISUAL · REFERENCIAS MORFOLÓGICAS**

## Dirección artística

### 1968
- meseta abierta;
- monte bruto;
- pocos elementos humanos;
- río como gran referencia espacial;
- ausencia de urbanización visible;
- colores secos y naturales.

### 1969
- misma base territorial;
- aparición progresiva del agua de riego;
- primeros cultivos;
- transición muy visible entre secano y área intervenida.

### 1973
- territorio productivo ya transformado;
- núcleo urbano pequeño;
- caminos y actividad humana;
- contraste fuerte entre meseta y área irrigada.

### Hoy
- mosaico productivo;
- localidad consolidada;
- alamedas, viñedos/frutales y corredores verdes donde corresponda;
- meseta/bardas como estructura territorial persistente.
